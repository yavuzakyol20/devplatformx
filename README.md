# DevPlatformX

Internal Developer Platform Mini built with .NET, SQL Server, Docker, Kubernetes, CI/CD, and observability tools.

## Goal

DevPlatformX is a small internal developer platform that helps development teams manage services, deployments, environments, and operational visibility.

## Tech Stack

- .NET / C#
- SQL Server
- Docker
- Kubernetes
- GitHub Actions
- Prometheus
- Grafana
- Loki
